# V0.1.1 feel print

`equip-1-V0.1.1-feel.3mf` holds the bottom shell (opening up), the top shell (flipped onto its
top face) and the screen cover, as detached closed manifold meshes on one bed. Units are
**mm, print at 100% scale**.

- Bed footprint: 197.0 × 60.6 mm, tallest part 14.2 mm.
- Assembled size: 72.1 × 60.6 × 21.7 mm. The switch actuators stand about 1.5 mm proud when the Firehat Rev 4 is fitted.

This is for checking size and feel only. It is **not functional**: there is no support strategy
or printer-specific tolerance tuning, and the real screen cover is a bought window/adhesive
part. Generated by `scripts/export.py` from the `.FCStd` named in `../reports/validation.md`;
the CAD is not saved during export.
