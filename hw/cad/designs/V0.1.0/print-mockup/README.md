# V0.1.0 feel print

`equip-1-V0.1.0-feel.3mf` holds all six parts as detached, closed
manifold meshes laid out on one bed. Units are **mm, print at 100% scale**.

- Bed footprint: 237.3 × 60.6 mm, tallest part 16.5 mm.
- Left to right: bottom shell (opening up), top shell (flipped onto its top face), screen cover, buttons 1–3 (flange down).
- Assembled size: 72.1 × 60.6 × 24.0 mm (25.5 mm over the buttons).

This is for checking size and feel only. It is **not functional**: there is no support strategy,
no tolerance tuning for a particular printer, no electronics fit check, and the real screen
cover is a bought window/adhesive part. Generated by `scripts/export.py` from the `.FCStd`
named in `../reports/validation.md`; the CAD is not saved during export.
