# Source

Runtime application, UIs, image build tooling, and development service templates for Equip-1 / Firehat.

Documentation starts in [`docs/`](docs/README.md). The old `buildroot/docs/` notes now live in [`docs/buildroot/`](docs/buildroot/README.md).

- `equip1d/` — recorder daemon and HTTP/WebSocket API
- `uis/oled/` — OLED/buttons frontend
- `uis/web/` — Nuxt web dashboard
- `buildroot/` — appliance image tooling and root filesystem overlay
- `docs/` — source architecture, daemon/API, UI, storage, settings, and Buildroot notes
- `systemd/` — optional Debian/Radxa development service templates
- `scripts/` — helper scripts used by development services
- `fonts/` — OLED UI fonts
